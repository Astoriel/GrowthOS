# Known Limitations

**Snapshot date:** 2025-12-15

- Some modules are intentionally marked as planned placeholders while the core workflows mature.
- Demo mode is useful for evaluation but should not be confused with live connector coverage.
- The product surface is broad; the recommended evaluation path is weekly growth review, funnel diagnosis, and channel efficiency review.
- Connector coverage varies by source and may require manual credential and schema setup.
- Analytical outputs should include assumptions and source tables; this trust layer is still being improved.
- The project should remain explicit about experimental status until recurring workflow reliability is proven.
