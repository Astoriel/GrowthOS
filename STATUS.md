# Project Status

**Status:** Experimental beta  
**Snapshot date:** 2025-12-15  
**Primary audience:** founders, growth leads, and analytics consultants testing AI-assisted growth analytics through MCP.

`GrowthOS` is an MCP analytics prototype for funnel analysis, CAC/LTV, retention, attribution, anomaly checks, and weekly summaries. The strongest current value is in a narrow set of repeated workflows over CSV/DuckDB/Postgres-style data, not in being a complete analytics platform.

## Current Confidence

- Working: MCP tool registry, DuckDB-backed demo mode, SQL safety tests, schema/metric utilities, several workflow tools, early real-source connectors.
- Planned: GA4 connector, query cache, query planner, richer trust metadata, scheduled reports, broader connector hardening.
- Not claimed: full BI platform replacement, universal marketing data connector, fully automated root-cause analysis.
